# Archived provider inventory

The machine-readable inventory in this directory was a research snapshot, not
a runtime source of truth. It is no longer maintained and has been removed from
the current checkout.

- Current OpenAI-compatible provider configuration:
  [`aimux-providers/src/provider_registry.json`](../aimux-providers/src/provider_registry.json)
- Current provider-development evidence rules:
  [RFC-0006](../rfc/0006-provider-development.md)
- Historical inventory, including provenance and candidate metadata:
  [commit `892a351`](https://github.com/arcships/aimux/tree/892a351fd85bf94986e9ba765dcd77c721474f31/provider-inventory)

The historical snapshot remains useful for research, but official provider
documentation or SDKs must be re-verified before implementing an adapter.
