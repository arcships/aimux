# Upgrading to the ops ABI

Upgrade the native library, header, language packages and generated metadata
together. ABI 1 (`65536`) and ops `1.0` replace the unversioned exports and
provider-specific constructors. Rebuild native consumers against
`aimux-ffi/include/aimux.h`. There are no old ABI forwarding aliases.

## Breaking changes

| Previous usage | Current replacement |
|---|---|
| `aimux_openai_new`, language-specific one-shot/vendor constructors | `provider.create`, then `provider.model` with explicit method/modelId |
| Payload-specific C error getters | `aimux_error_json`; code/message/free remain, with new ownership rules |
| Global provider registration | Explicit `registry.create` entries and `model.resolve` |
| Realtime transcription session pointer | Operation handle from `transcription.start`, binary push and typed poll |
| NULL/on_done stream completion | Business event frames and one explicit transport end |
| Global recording/session convenience initialization | Explicit recorder/sessionStore creation and attachment; capture still process-wide |
| Kotlin's independent native loader and DTO copies | Matching Java artifact plus `ai.arcships.aimux.kotlin` coroutine helpers |
| Old wire fields or permissive settings | Exact current control fields and canonical business JSON; unknown controls fail |

Business DTOs and codecs of every binding are generated by aimux-codegen from the
Rust types (#268); the hand-written DTO types, including Java `Types` and
`MultimodalTypes`, are removed. See the Unreleased entry in `CHANGELOG.md` for the
new location in each language.
Python's former top-level model helpers are replaced by Client/Handle dispatch;
Node has Client and typed resource facades. Go and Swift primarily expose the
shared handle/operation interface. Check the actual API below before renaming.

Recording writers use schema 2 and readers accept schemas 1 and 2, as defined
in `aimux-core/src/recording.rs`. Migration to schema 3 and removal of old-schema
reading are scheduled for a separate follow-up PR after #268, before the release,
under RFC-0041. Preserve
original files. A future recording change can make rollback unable to read new
data; no automatic converter or compatibility release is promised. Pin the
entire previous release when rolling back, including packages and native assets.

## Load and validate

Read the ABI and manifest before creating resources. Raw C consumers must check
the ABI major, their required ABI minor, exact expected opsVersion, required
operations and kinds. There is no FFI minor negotiation or stdio hello. The
manifest digest identifies canonical metadata, not binary identity.

Python verifies its generated ABI/ops/digest at import. Node checks ABI/ops and
exposes manifestDigest; it does not currently enforce a generated-digest match.
Go, Java, Swift and Dart enforce their implemented ABI/ops checks, and Dart can
require operation names. Per-business-type schema revisions/hashes are not yet
available. Use one coherent release set; these current checks do not replace
the missing per-type compatibility gate.

## Provider → model in eight interfaces

Each example uses an OpenAI language model. Set credentials through your
environment or current settings, and replace the model ID with one supported by
your account. The API names and argument order below come from this tree; the
snippets demonstrate calls and do not claim a successful provider network run.

### C / C++

C has only the fourteen primitives; use your JSON library to extract the
decimal `handle` field from resource results. The calls are:

```c
/* After ABI/manifest checks; provider and model are parsed uint64_t IDs.
 * Each call returns an owned error or NULL; handle it before using output. */
char *provider_json = NULL;
aimux_error_t *error = aimux_call(0, "provider.create",
    "{\"package\":\"openai\",\"settings\":{}}", 0, &provider_json);
/* On success: parse provider_json.handle, then aimux_free_string(provider_json). */
char *model_json = NULL;
error = aimux_call(provider, "provider.model",
    "{\"method\":\"languageModel\",\"modelId\":\"gpt-4o-mini\"}", 0, &model_json);
/* On success: parse model_json.handle, then aimux_free_string(model_json). */
char *result_json = NULL;
error = aimux_call(model, "text.generate", "{\"prompt\":\"Hello\"}", 0, &result_json);
/* Handle error, then release result_json and both handles. */
aimux_free_string(result_json);
aimux_drop(model);
aimux_drop(provider);
```

The fragment shows native calls; the comments mark required JSON parsing and
error handling, rather than a complete standalone program. For executable
offline examples see [example.c](../bindings/c/example.c) and
[example.cpp](../bindings/c/example.cpp). C++ can use `aimux::Handle`,
`aimux::String`, `aimux::Error` and `aimux::check` from `bindings/c/aimux_raii.hpp`.
`aimux::stream` catches callback exceptions before crossing C and rethrows the
saved exception after return. C callers must implement equivalent latching.

### Go

```go
ctx := context.Background()
provider, err := aimux.Create(ctx, nil, "provider.create", map[string]any{
    "package": "openai", "settings": map[string]any{},
})
if err != nil { return err }
defer provider.Close()
model, err := aimux.Create(ctx, provider, "provider.model", map[string]any{
    "method": "languageModel", "modelId": "gpt-4o-mini",
})
if err != nil { return err }
defer model.Close()
result, err := aimux.CallInto[aimux.GenerateTextResult](ctx, model, "text.generate",
    map[string]any{"prompt": "Hello"})
if err != nil { return err }
fmt.Println(result.Text)
```

Use `aimux.Call` for globals, `Handle.Call`/`Handle.Stream` for resources and
`Create` to adopt returned handles. Context cancellation signals Abort.
Consume `Stream.Events()` and check `Stream.Err()` after completion; close an
abandoned stream. `Handle.StartOperation` returns an Operation with `Push`,
`InputDone`, `NextPart`, `Status`, `Cancel` and `Close`. The cgo fixture suite
and real-library suite exercise different boundaries.

### Java

```java
Aimux client = Aimux.load();
try (ProviderHandle provider = client.createProvider(
         "{\"package\":\"openai\",\"settings\":{}}");
     Model model = provider.languageModel("gpt-4o-mini")) {
    System.out.println(model.generate("{\"prompt\":\"Hello\"}"));
}
```

Imports are from `ai.arcships.aimux`. Java 8 remains supported. Use
`Aimux.create`/`Resource.call` for registry, recorder, trace, session and replay
operations. `ProviderHandle` exposes the modality constructors and files;
`decisionModel(id)` selects method `decision`. Async methods such as
`Model.generateAsync(params, executor)` require an explicit Executor. Future
cancellation signals native Abort, including before execution; interrupting a
thread is not the native cancellation mechanism. Close and cancellation have
separate lifetimes. A Consumer gets a copied `StreamFrame`, including End;
terminal errors are raised after native return. Consumer failures are latched
and cannot cross C. `TranscriptionSession.next(timeoutMs)` returns PART/ENDED/
TIMEOUT. Existing DTO builders remain; no blanket builder deletion is required.

### Kotlin

```kotlin
import ai.arcships.aimux.Aimux
import ai.arcships.aimux.StreamFrame
import ai.arcships.aimux.kotlin.aimuxCall
import ai.arcships.aimux.kotlin.aimuxFlow
import kotlinx.coroutines.flow.collect

suspend fun generate() {
    val client = Aimux.load()
    client.createProvider("""{"package":"openai","settings":{}}""").use { provider ->
        provider.languageModel("gpt-4o-mini").use { model ->
            val params = """{"prompt":"Hello"}"""
            println(aimuxCall { executor -> model.generateAsync(params, executor) })
            aimuxFlow<StreamFrame> { executor, consumer ->
                model.streamAsync(params, consumer, executor)
            }.collect { frame -> println(frame.json) }
        }
    }
}
```

Use Java resources and DTOs plus the Kotlin helpers; the old independent Kotlin
model/factory/Sequence API is removed. The artifact strictly pins same-version
`ai.arcships:aimux-java`. `aimuxCall`, `awaitAimux` and bounded `aimuxFlow` use
IO execution and forward cancellation to Java Future/Abort. The sealed Kotlin
AimuxException projects Java domain errors rather than decoding JSON again.

### Swift

```swift
let provider = try await AimuxRuntime.open(AimuxOps.OP_PROVIDER_CREATE, params: .object([
    "package": .string("openai"), "settings": .object([:]),
]))
defer { provider.close() }
let model = try await provider.open(AimuxOps.OP_PROVIDER_MODEL, params: .object([
    "method": .string("languageModel"), "modelId": .string("gpt-4o-mini"),
]))
defer { model.close() }
let result = try await model.call(AimuxOps.OP_TEXT_GENERATE,
    params: .object(["prompt": .string("Hello")]))
print(result)
```

`AimuxRuntime` addresses globals; `AimuxHandle` owns UInt64 IDs. `call`/`open`/
`stream` run blocking C work on GCD threads. `BoundedStream` is the bounded
AsyncSequence; call `cancel()` on stored iterators when abandoned. Task cancellation signals
Abort. `push(Data)` and `nextPart(timeoutMs:)` use binary/poll primitives;
closing an active Operation requests cancellation. ARC cleanup is a fallback,
not a flush. Existing Codable DTOs remain; dictionary re-encoding can change
object-key order. macOS execution alone does not verify iOS simulator linking.

### Dart / Flutter

```dart
final client = await Aimux.open(requiredOps: ['provider.create', 'text.generate']);
final providerResult = await client.call('provider.create',
    params: {'package': 'openai', 'settings': <String, dynamic>{}})
    as Map<String, dynamic>;
final provider = client.adopt(providerResult['handle'] as String);
try {
  final modelResult = await client.call('provider.model', handle: provider,
      params: {'method': 'languageModel', 'modelId': 'gpt-4o-mini'})
      as Map<String, dynamic>;
  final model = client.adopt(modelResult['handle'] as String);
  try {
    print(await client.call('text.generate', handle: model, params: {'prompt': 'Hello'}));
  } finally { await model.close(); }
} finally { await provider.close(); }
```

Import `package:aimux/aimux.dart`. Adopt each returned handle once. Blocking
calls/push/poll/drop run on background isolates; Future abandonment alone does
not cancel. Create Abort explicitly and use `client.abort(abort)` when needed.
Raw streams expose EndFrame with any terminal error once; TypedModel projects
it into its typed error behavior. Pause withholds credit; subscription cancel
wakes the bridge without waiting for credit. NativeCallable.listener delivers
notifications on the owning isolate. NativeFinalizer uses its allocated uint64
token trampoline; do not cast a uint64 drop function to a pointer callback.
Windows streaming is unsupported because the credit bridge uses POSIX pipes.
Android ABI packaging and iOS static force-linking require their platform gates.

### Node.js / TypeScript

```typescript
import { Client, LanguageModel } from '@arcships/aimux'
const client = new Client()
const provider = await client.provider({ package: 'openai', settings: {} })
try {
  const model = await provider.model('gpt-4o-mini', 'languageModel')
  try {
    if (!(model instanceof LanguageModel)) throw new Error('Expected language model')
    console.log((await model.generate('Hello')).text)
  } finally { await model.close() }
} finally { await provider.close() }
```

Typed calls use `Client.call(handle, op, params)` and resource helpers; the raw
`Runtime.call(handle, op, paramsJson)` returns JSON strings. Streams are async
iterators of event/end frames. Pass `{signal}` or `{abort}`, not both;
iterator.return and ReadableStream reader.cancel propagate cancellation.
`Client.abort()` and Operation.cancel are explicit controls. Handles belong to
one Env and cannot be transferred across Envs. The native addon calls shared
Rust dispatch, never the synchronous C adapter. The native lifecycle test
expects trace middleware creation and model wrapping to succeed.

### Python

```python
from aimux import Client

client = Client()
provider = client.call("provider.create", {"package": "openai", "settings": {}})
with client.adopt(provider["handle"]) as provider_handle:
    model = provider_handle.call("provider.model", {
        "method": "languageModel", "modelId": "gpt-4o-mini",
    })
    with client.adopt(model["handle"]) as model_handle:
        print(model_handle.call("text.generate", {"prompt": "Hello"})["text"])
```

`Client.call(op, params, handle=..., abort=...)` returns Python JSON values.
`Handle.call` binds a handle; `Handle.stream` returns a synchronous EventStream
context manager. The iterator yields event frames, consumes successful end,
and raises a typed exception for failed/cancelled end. Close/cancel/join release
the GIL on blocking native paths. This is not an async generator: use your
executor for asyncio integration. `Abort.cancel()` signals; dropping it does
not. `Client.operation_push`/`Handle.push` accept bytes-like input; poll via
`operation.next` with timeoutMs. The native PyO3 package remains; optional
Pydantic codecs do not replace native dispatch. Subinterpreter import support
is constrained by the current PyO3 version.

## Common request and lifecycle changes

Text uses `{"prompt":...,"options":{...}}`. Embedding uses `values` (both embed
names currently call the canonical multi-value function); transcription uses
base64 `audio` and mediaType. Decision uses `{"options":...}`. Method names are
languageModel, embeddingModel, imageModel, speechModel, transcriptionModel,
rerankingModel, videoModel, searchModel and decision. Files uses provider.files.
Treat control keys and op names as case-sensitive. Handles and seq are decimal
strings in JSON, including IDs above 2^53. Do not substitute pointers or numbers.

Use explicit recorder.create → recorder.attach → recorder.flush/stop/export;
flush reports persistence failures. Use sessionStore.create with explicit infer
and attach the selected store. Their capture state remains process-wide across
C clients and Node/Python owners. TraceStore and Middleware are distinct handles.
Replay accepts recordingsJsonl, inspect/dryRun and explicit Language/Decision
targets for replay.live; transport replay and credential.create currently raise
UnsupportedFunctionality, not empty success.

Dropping an ordinary model does not cancel an admitted call. Dropping Abort
does not signal it; dropping Operation cancels it. Finalization is leak
prevention, not guaranteed flush or successful completion. Raw binary push is
limited to 1 MiB and returns ResourceLimit when input admission is full; JSON
operation.push is InvalidOp. Poll part/ended/timeout are distinct and a poll
timeout does not end the operation. Queues have independent terminal slots.

Read `kind`, `code`, `message` and `error` from errors. Use `error.name` and
`error.isRetryable` where defined; there is no top-level retryable or type. 0.5's
`aimux_error_retry_ms` (Node `retryMs`, Python `retry_ms`) has no replacement
field: read the delay from `error.responseHeaders` (`retry-after-ms`,
`retry-after`), as with the AI SDK. Preserve nested causes/history and unknown
payloads. Bindings never add a retry loop. Cancellation
cannot revoke a completed billable submission; a disconnected request can have
an unknown outcome, so do not automatically replay it. Callbacks must return in
bounded time: Abort cannot interrupt a callback that never returns.

The [implementation document](rfc-0039-implementation.md#registered-gaps) lists
remaining schema, provenance, memory-bound and platform verification gaps.
The [conformance matrix](rfc-0039-conformance.md) records existing tests without
claiming unexecuted platforms passed. Stdio and arbitrary host provider
callbacks are outside the current API.
