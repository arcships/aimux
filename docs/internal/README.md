# Internal notes

This directory holds historical research, audit, and handoff notes that are
**not** part of aimux's public documentation surface. It is kept for
reference only and generally does not need changes.

## Contents

| Subdirectory | Contents |
|--------------|----------|
| `handoff/` | Project handoff, tracking, quality-review, remediation, test-audit, and clone-list notes |
| `vercel-research/` | Systematic research notes on the Vercel AI SDK source (`reference/ai/`), used as design reference |
| `audit/` | Feature-coverage, binding, FFI, language-coverage, and architecture audits |
| `provider-research/` | Per-batch provider research for the inventory |

For public docs, see the [top-level README](../../README.md) and
[docs/README.md](../README.md).
