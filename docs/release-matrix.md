# Release & CI Platform Matrix

This matrix records the exact build, test, packaging, and installation coverage
defined in [`.github/workflows/ci.yml`](../.github/workflows/ci.yml) and
[`.github/workflows/release.yml`](../.github/workflows/release.yml).
Cells that are cross-compiled without native execution, omitted from CI/release
workflows, or not installed from the published artifact are explicitly marked
`not run` (see [RFC-0039 registered gap G-e](rfc-0039-implementation.md#registered-gaps)).
